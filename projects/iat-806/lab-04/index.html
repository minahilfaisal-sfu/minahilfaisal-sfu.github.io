Lab 04 — Grid of Dancers

Displays a grid of dances, at varying speeds dependant on mouse position.

Implementation Notes

  • Added 5 different dances of 14 frames each to display in the grid cells
  • Each dance is displayed in a grid cell with a unique color and speed
  • Mouse X controls the number of columns on the grid
  • Mouse Y controls the number of rows on the grid
  • Distance from the mouse determines the speed of the dance (closer = faster)
  • Ensured somewhat proportional scaling of rows, columns and image width and height.
