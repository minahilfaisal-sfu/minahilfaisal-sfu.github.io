Lab 03 — Animations

This lab explores the creation of animations frame by frame using p5.js.

Implementation Details

  • Press the space key to start and stop the animation.
  • Created an animation by hand of V (Kim Taehyung) dancing to the song "ON" by BTS.
  • Uploaded an audio clip for this dance break from the original video.
On Mouse Click:
  • The animation starts playing / gets reset.
  • The background music starts playing / gets reset.
  • Canvas border color randomizes on each frame to mimic a disco light effect.
On Key Click (Space Bar):
  • The animation starts pauses / resumes playing.
  • The background music pauses / resumes playing.
  • Canvas border color randomizes on each frame to mimic a disco light effect.
Bonus - On Key Click (X key):
  • Only the animation starts pauses / resumes playing.
  • The background music remains as it is (playing or paused).

Notes

This lab focuses on for loops, arrays, and loading images to create animations.

P.S. I actually made this animation in Summer of 2020 because I was obsessed with this song and this fancam. I made this frame by frame (69 frames in total) by handin photoshop when the original inspo video (KBS Kpop, 2020, 1:35–1:40) first came out. I'm glad I am able to showcase it here now. No AI used in creating the animation.
